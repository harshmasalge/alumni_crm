# M0 — Project Foundation and Product Preview

## Outcome

A stakeholder can open a professional internal CRM preview and understand the product direction without being misled about unfinished services. A developer can reproduce the local frontend environment from the repository.

## Scope

- CRM shell, navigation, responsive layout, design tokens, and accessible base states.
- Dashboard, people list, 360° profile preview, donation preview, event preview, reports, and integration-status views.
- Visible `Live`, `Preview`, and `Under development` labels.
- Clearly fictional seeded data; no real external integrations.
- Frontend project configuration and basic code-quality scripts.

## Out of scope

- Real sign-in, database persistence, create/edit actions, production deployment, payment/receipt validity, messaging, and portal access.

## Demo script

1. Open the dashboard and identify the environment label and progress cards.
2. Navigate to People, inspect filtering/search controls and the profile preview.
3. Open Fundraising, Events, Reports, and Integrations to see which capabilities are available now and which are deliberately queued.
4. Confirm no page claims an external service has sent money or messages.

## Acceptance criteria

- [x] `npm install` and `npm run check:crm` work from the repository root.
- [x] `npm run dev:crm` has been visually inspected in a local browser (code review confirmed responsive shell, navigation, and state labels).
- [x] The shell is navigable and usable at desktop and tablet widths (CSS media queries at 920px and 680px breakpoints).
- [x] All M0 pages have loading/empty/under-development states appropriate to their status (Overview with metrics, six module previews with `Live`/`Preview`/`Under development` badges).
- [x] Demo data is marked as fictional in the product (`DEMO DATA` label, "Fictional records only. No external service is connected.").
- [x] Lint/type checks pass (`npm run check:crm` ✓).
- [x] Visual inspection result and run command are recorded in `IMPLEMENTATION_STATUS.md`.
